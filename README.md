# FlyRank operations review

[Open the dashboard](https://mirzaasca.github.io/flyrank-operations-review/).

Evidence review ready for decision, 12 October 2026: 80 project dossiers, 527 reconstructed work episodes, client journeys, participant roles, platform differences, commercial evidence and eight ordered implementation specifications.

Start with the Roadmap and Economics views. Employee hourly rates are unavailable; the calculator defaults to illustrative capacity hours and leaves dollar results unknown. Plans and project age do not establish actual revenue or paid tenure. Implementation specifications have not been deployed.

Public client findings and source references are included with owner authorization. Raw exports and credentials are not included. Source links require existing access to their original systems. Unavailable sources and measurement limits remain explicit.

All ten views were checked at 320, 390, 768 and 1440 pixels, including filtering, CSV export and calculator edge cases. Open index.html locally or use GitHub Pages; no Live Server extension is required.
